The word is **Slotmachine**. The human checks the bounty board every hour on the hour, pulls the lever, and hands whatever comes out to his black-cat AI agent — delegation as a game of chance, played on a loop.

## How to run

```sh
python3 main.py
```

It writes exactly one word, no trailing newline, to /output/entry.txt. Pure Python 3.13 standard library, deterministic — the same bytes on every run.
